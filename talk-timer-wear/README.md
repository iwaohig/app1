# プレゼンタイマー（Pixel Watch / Wear OS）

発表の残り時間を手首の振動で知らせる Wear OS アプリです。スマホアプリなしで、時計単体で動きます。

## できること

- 持ち時間を 1〜180 分で自由に設定（リューズを回すか、画面の − / ＋ で 1 分ずつ）
- 残り時間に応じて自動で振動。発表中の操作は不要です

  | タイミング | 振動 |
  |---|---|
  | 持ち時間の半分、残り10分、残り5分（半分より後のものだけ） | 短く1回 |
  | 残り3分 | 短く2回 |
  | 残り1分 | 短く3回 |
  | 時間切れ | 長く1回 |
  | 超過中 | 1分ごとに長く1回（最大60分） |

  例：60分 → 残り 30・10・5・3・1 分／30分 → 15・10・5・3・1 分／20分 → 10・5・3・1 分

- 画面：「残り」＋大きな残り時間、色の変わるリング（緑 → 残り3分で黄 → 残り1分で赤）、振動の位置の目盛り、`現在 14:07 → 終了 14:32`
- 画面をタップで開始・一時停止。一時停止中は「リセット」ボタンが出ます
- 画面が消えても振動は時間どおりに鳴ります（アラームで予約しているため）
- 常時表示（アンビエント）モード対応：色を消し、分単位で表示
- Ongoing Activity：計測中はウォッチフェイス上にアイコンが出て、すぐアプリに戻れます
- タイル：持ち時間を表示し、ワンタップで開始
- コンプリケーション：ウォッチフェイスの枠に残り時間を表示（ウォッチフェイス側が自動でカウントダウン）
- 日本語・英語・韓国語・中国語（簡体字）。時計の言語設定で自動的に切り替わります

## フォルダ構成

```
app/src/main/java/com/iwaohig/talktimer/
  TimerLogic.kt        振動のタイミング・パターン・色・表示形式（純粋なロジック）
  TimerState.kt        タイマーの状態
  TimerStore.kt        状態の保存（アプリが終了しても残る）
  TimerController.kt   開始・一時停止・リセット・時間変更
  AlarmScheduler.kt    振動をアラームとして予約
  AlertReceiver.kt     アラームを受けて振動し、超過中の次の振動を予約
  Haptics.kt           振動
  OngoingNotifier.kt   Ongoing Activity（計測中の通知とアイコン）
  MainActivity.kt      画面と常時表示モード
  ui/TimerScreen.kt    時計の画面（Compose for Wear OS）
  tile/                タイル
  complication/        コンプリケーション
app/src/main/res/values*/strings.xml   各言語の文字
app/src/test/                          ロジックの単体テスト
```

## ビルド

必要なもの：Android Studio（または JDK 17 以上と Android SDK 36）

```bash
cd talk-timer-wear
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk ができる
./gradlew testDebugUnitTest      # 単体テスト
./gradlew lintDebug              # Lint
```

Android Studio の場合は `talk-timer-wear` フォルダを開いてください。

## Pixel Watch に入れる

1. 時計で「設定 → システム → デバイス情報 → バージョン → ビルド番号」を7回タップし、開発者向けオプションを有効にする
2. 「設定 → 開発者向けオプション」で「ADB デバッグ」と「ワイヤレス デバッグ」をオンにする（PC と同じ Wi-Fi に接続）
3. PC から接続してインストール

   ```bash
   adb pair <IP>:<ペア設定用ポート>   # 「新しいデバイスとペア設定」に出る IP・ポート・コード
   adb connect <IP>:<ポート>          # ワイヤレス デバッグ画面に出ている IP・ポート
   ./gradlew installDebug
   ```

4. 時計のアプリ一覧から「プレゼンタイマー」を開く。初回は通知の許可を求められます（計測中のアイコン表示に使います。許可しなくても振動は鳴ります）
5. タイルは時計の画面を左にスワイプして「＋」から、コンプリケーションはウォッチフェイスの編集画面から追加できます

## 権限

| 権限 | 用途 |
|---|---|
| `VIBRATE` | 振動 |
| `POST_NOTIFICATIONS` | 計測中の Ongoing Activity 表示 |
| `USE_EXACT_ALARM`（API 33+） / `SCHEDULE_EXACT_ALARM`（API 32 以下） | 画面が消えていても振動を時間どおりに鳴らす |
